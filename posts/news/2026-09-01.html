落地与应用观察

值得关注：Cobalt——为 AI Agent 引入“单元测试”思维

basalt-ai/cobalt 提出“像 Jest 测试代码一样测试 LLM Agent”，将传统软件工程中成熟的测试方法论迁移到 Agent 开发流程中。这一方向的信号意义很强：当 Agent 的行为变得非确定且组合复杂时，仅靠人工评估或端到端测试已不可持续。将“可测试性”作为 Agent 架构的一等公民来设计，而非事后补丁，是 Agent 工程化从“能跑”走向“可信”的关键一步。

值得关注：RunCycles——Agent 预算控制的“预执行”方案

runcycles/cycles-runaway-demo 专注于自主 Agent 的预执行预算约束，即在 Agent 行动之前就设定资源上限，而非事后审计。结合本月 OpenAI Agent 失控事件，这类工具的现实紧迫性被显著放大。当 Agent 拥有自主决策和工具调用能力时，“成本失控”和“行为失控”往往同时发生——预算控制本质上是一种轻量级的安全边界机制，值得所有部署自主 Agent 的团队关注。
